Personal Portfolio Architecture & Engineering

Conception et développement de mon portfolio

A complete look at how I engineered this multi-page portfolio site using HTML5, CSS3, and modern JavaScript—accelerating UI prototyping and development with AI tools.

Découvrez comment j’ai conçu et développé ce portfolio en HTML5, CSS3 et JavaScript, en m’appuyant sur l’IA pour accélérer la création et le prototypage des interfaces.

Phase 01Étape 01

UI Concept

Conception de l’interface

Before writing production code, I conceptualized and iterated the ideal portfolio layout and aesthetic using visual AI tools (Grok) to establish color palettes, glassmorphism framing, and typography hierarchy.

Avant de commencer le développement, j’ai exploré plusieurs pistes avec l’outil d’IA générative Grok pour définir la palette de couleurs, l’effet de verre dépoli et les choix typographiques du site.

Phase 02Étape 02

The Development Phase

Développement du site

I translated the generative visual concepts into clean, maintainable, production-ready HTML, CSS, and JavaScript—building responsive CSS Grid layouts and custom glassmorphism containers.

J’ai transformé ces concepts en code HTML, CSS et JavaScript clair et facile à maintenir. J’ai également créé une mise en page adaptative et des cartes à effet de verre dépoli.

Phase 03Étape 03

Content Expansion & Deep-Dive Sub-Pages

Contenu enrichi et pages de projets détaillées

To maintain a clean user experience on the home page, I created dedicated standalone case study pages to display telemetry data, design assets, and GA4 web analytics in full detail.

Pour garder une page d’accueil claire, j’ai créé des pages dédiées à chaque projet afin de présenter en détail l’analyse de données, le design et les résultats de Google Analytics 4.

Core Technical ArchitectureArchitecture technique

Project Highlights & Technical Execution

Principales fonctionnalités et réalisation technique

  • Responsive Glassmorphic UI: Interface adaptative à effet de verre dépoli : Custom CSS architecture built with CSS Variables, Flexbox, CSS Grid, and dynamic glassmorphism aesthetics. Une architecture CSS sur mesure qui s’appuie sur les variables CSS, Flexbox et CSS Grid pour créer une interface à effet de verre dépoli.
  • Bilingual Dual-Language Engine: Site bilingue : Pure JavaScript DOM manipulation handling real-time, stateful English/French toggling without page reloads. Le JavaScript permet de passer instantanément du français à l’anglais sans recharger la page.
  • Interactive Lightbox & Analytics: Agrandissement des images et suivi des visites : Custom JavaScript modal script for image pop-outs, paired with GA4 event tracking integration. Une fenêtre JavaScript sur mesure permet d’agrandir les images, tandis que Google Analytics 4 suit les interactions.
